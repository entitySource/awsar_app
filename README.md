# AWSAR + EduAnchors app (Flutter)

Bilingual (English | हिंदी), offline-first Android app for AWSAR India and EduAnchors. Built for FOSS Forge 2.0.

## Run on your phone (Windows PowerShell, one command per line)

```powershell
cd C:\dev\awsar_app
flutter pub get
flutter run
```

Release APK:

```powershell
flutter build apk --release
adb install -r build\app\outputs\flutter-apk\app-release.apk
```

## Turn on login (Supabase)

Without keys the app runs fully offline and the Account screen says sign-in is off. To turn it on:

1. Supabase dashboard > **SQL Editor**: paste `supabase/migrations/20261021000000_saved_opportunities.sql` and **Run**.
   It creates `saved_opportunities` with row level security (each user sees only their own rows).
2. **Authentication > Sign In / Providers > Email**: keep it on. For a smooth demo, turn off **Confirm email**
   so a new account is signed in straight away (leave it on for real users).
3. **Project Settings > API Keys**: copy the Project URL and the **publishable** key
   (never the secret / service_role key).
4. Copy `supabase.example.json` to `supabase.json` (git-ignored), fill in both values, then:

```powershell
flutter run --dart-define-from-file=supabase.json
flutter build apk --release --dart-define-from-file=supabase.json
```

What an account does: saved opportunities sync to the account (merged with what was saved on the phone),
and the Donate and Volunteer forms start filled in with the name, email and mobile given at sign-up.

## Check

```powershell
dart format -l 120 lib test
flutter analyze
flutter test
```

`flutter test` runs 76 tests: content parsing (EN and HI), ARB parity, every tab, the EN/HI toggle,
form validation, the email hand-off, sign in/up/out with a fake backend, saved-list merging, form prefill, and Android accessibility guidelines plus no overflow at 2x text
on every screen in both languages.

## What's where

- `lib/app/`: theme, router (5 tabs), shell
- `lib/core/content/`: content models and the repository (per-file English fallback)
- `lib/core/auth/`: accounts (Supabase, or disabled when no keys) and the cloud saved list
- `supabase/migrations/`: the database table and its security rules
- `lib/features/<feature>/`: Home, Programmes, Opportunities, Get involved, About/Contact/Media, More
- `lib/l10n/app_en.arb`, `app_hi.arb`: UI strings (Hindi is a draft translation)
- `assets/content/{en,hi}/*.json`: bundled content, so every screen works offline

## Design system (UI-UX Pro Max)

`design-system/awsar-india/MASTER.md` was generated by the UI-UX Pro Max skill (bundled in
`.claude/skills/ui-ux-pro-max`): Trust & Authority layout, Swiss minimal style, cyan primary with an
orange accent kept for the one donate action per screen, Lexend headings and Source Sans 3 body
(Hindi falls back to Noto Sans Devanagari). Light and dark themes follow the phone setting. Tokens
live in `lib/app/theme.dart`.

## Content status

The bundled content is seed content quoted from awsarindia.org and eduanchors.com. The three
opportunities are labelled **Sample**, and Photos/Videos/Reports is empty until you run the scraper
(`scripts/scrape-sites.mjs`) and the build-content step from the plan.
